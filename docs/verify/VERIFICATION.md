# 검증 기록

어느 기능을 무엇으로 확인했는지의 색인이다. 명령과 출력, 조건, 한계는 각 실험의 README에 있다.
새로 확인한 것이 생기면 표에 한 줄을 더한다.

단위 테스트는 `./gradlew test`로 돈다. 2026-10-18 기준 246개다. 실험은 도커가 필요하고 CI에서 돌지 않는다.

## 확인하지 못한 것

- 네이티브 Linux와 운영급 장비에서의 수치
- 한 시간 넘는 실제 녹화. 12GB의 가짜 로그까지만 변환해 봤다(실험 10). 큰 트래픽 파일의 재생과 비교는 해 보지 않았다
- 서버가 따로인 복제 구성. 실험 11은 주 DB, 종 DB, 재생기가 한 장비였다. 종 DB가 둘 이상인 구성, 반동기 복제
- 읽기를 받는 노드를 늘리면 읽기 상한이 비례해 느는가 (확장·축소 권고의 가정). 1대에서 2대로 늘리자 1.73배(최소끼리) 올랐지만 퍼짐이 커서 판정하지 못했다(실험 20, #109)
- 한 패킷에 여러 문장을 보내는 경우, `COPY`, `LOAD DATA`
- 녹화 전부터 autocommit이 꺼져 있던 연결
